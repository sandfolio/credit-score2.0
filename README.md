# Mint Money — Credit Scores

Interactive, responsive HTML prototype for CIBIL and CRIF credit scores.

## Run locally

Open `index.html` in a browser. No installation or build step is needed.

## Publish with GitHub Pages

1. Extract this ZIP.
2. Upload the contents of `mint-money-credit-scores-github` into your repository root.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose your branch and **/ (root)**, then save.

## Included

- CIBIL / CRIF tabs with animated scores and gauge
- Changes widget with parameter bottom sheets and Money Guru voice preview
- Five credit parameter cards in a horizontal carousel, opening full-page details
- Score history graph, loan and credit card offers, Help & Support
- Floating glass bottom navigation

## Notes

This is a design prototype with illustrative financial data and offers. Voice controls are simulated; the microphone is not activated. Applications, support requests and disputes are not submitted to external services.

All styles, JavaScript and illustrations are embedded in `index.html`. No external assets, dependencies, API keys or backend are required.
